# KB2CTF web challenges

Уязвимости приложений являются частью учебных заданий. Изоляция контейнеров
должна сохраняться даже после полного захвата приложения участником.

Перед запуском подготовьте Linux-хост по [инструкции изоляции](ops/README.md):
установите правила nftables и общий systemd slice, создайте ограниченные
постоянные хранилища. Compose использует внешние тома `*-bounded`; обычные
неограниченные Docker volumes вместо них не подходят.

Проверки конфигурации и регрессий:

```sh
python ops/check_isolation.py
python -m unittest discover -s ops -p 'test_*.py'
```

`ops/make_release.py` собирает обновление изоляции из приватного снимка
действующего релиза. Оно сохраняет действующие порты, флаги и образы приложений;
новый образ требуется только для Pinger Deluxe. Файлы релизов, production-флаги,
резервные копии и SSH-ключи должны оставаться вне Git.

После развёртывания выполняйте аудит фактических ограничений и сетевых границ
через `ops/check_isolation.py --runtime --network --require-apparmor` на хосте.
