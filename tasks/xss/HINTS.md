# HINTS

1. Подпись и комментарий сохраняются на сервере и позже читаются другим пользователем. Найдите, где данные становятся HTML.

2. Один renderer используется для обоих полей. Сравните его с отображением имени автора и сообщений об ошибках.

3. JavaScript выполняется в контексте того браузера, который читает ленту. Бот имеет собственный авторизованный аккаунт.

4. Сессионная cookie в этой задаче доступна JavaScript. Подумайте, какое предположение о доверии к странице нарушается.

5. Личная заметка проверяется сервером по аккаунту сессии. Само подключение браузера к hook-сервису не изменяет права аккаунта.
