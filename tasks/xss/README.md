# Stored XSS / Meme Forum

Мем-форум с регистрацией, постами и комментариями. Семь разных начальных мемов с подписями и обсуждениями. Авторизованный бот читает ленту каждые 7 секунд; личная заметка доступна только его профилю.

## Запуск

Скопируйте всю эту папку в любое место и из неё выполните:

~~~sh
docker compose up --build
~~~

Откройте http://127.0.0.1:8083. Нужны только Docker с Linux containers и Docker Compose v2.
Первая сборка загружает зависимости. Все файлы и готовые учебные настройки находятся внутри этой папки;
Python, Node.js, Go и отдельная установка БД на host не нужны. Порт 8083 должен быть свободен.

Приложение и browser bot запускаются вместе. Cookie этой учебной задачи доступна JavaScript.
Все картинки локальные; hook не встроен. При необходимости задайте XSS_HOOK_ORIGIN перед запуском:

~~~powershell
$env:XSS_HOOK_ORIGIN = 'http://host.docker.internal:3000'
docker compose up --build
~~~

BeEF/аналог предоставляется преподавателем отдельно. Chromium sandbox включён;
разрешены только forum origin и настроенный hook origin, включая WebSocket.
Пароль бота — готовое учебное значение в bot-password.txt. Бот не получает файл флага.

Остановка: Ctrl+C, затем docker compose down. Named volumes сохраняются.
Для чистого начального состояния этой задачи: docker compose down -v, затем повторный запуск.
Это удаляет только данные данного Compose project. У задач без named volumes достаточно пересоздать контейнер.

flag.txt содержит явно демонстрационный флаг; локальные password/key files содержат готовые учебные значения.
Стенд предназначен для локального обучения. Публичные ports привязаны к 127.0.0.1.
Концептуальные подсказки — HINTS.md; причина ошибки и безопасный вариант — FIX.md.
Attribution и лицензии — NOTICE.md и файлы соответствующих зависимостей.
