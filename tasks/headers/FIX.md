# FIX — Headers

Это вводная HTTP protocol task, а не production authentication.
Исходные специальные method/header/body conditions сохранены как учебные условия.
Custom header и постоянные значения не доказывают личность пользователя.
В реальном приложении используйте обычный документированный API, проверку структуры данных
и серверную authentication/authorization для чувствительных операций.
В безопасном API проверяйте также тип и структуру разобранного JSON. Исходный обработчик намеренно не усилен.
