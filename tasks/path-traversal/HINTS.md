# HINTS

1. Имя файла и фактический filesystem path — разные понятия.

2. Соединение base и filename ещё не гарантирует принадлежность файла base.

3. Сопоставьте canonical path с trusted directory, включая границу directory separator.

Флаг находится в `/flag.txt` в корне файловой системы сервера.
